# Predict 페이지 구현 계획

## 요구사항 분석

### 1. 예측 API 구조

- **Request**: `{"id":"ec711d89741eec656cf3", "seqno":0, "isRefrigerated":false}`
- **Response**:
  - predictions: [6.367591381072998, 6.1463518142700195, 5.959593296051025, 5.193045616149902, 6.4238667488098145]
  - xai_image_urls: S3 경로들
  - created_at: 생성 시간

### 2. 데이터 구조

- Dashboard에서 개별 데이터 API 호출 시 `by_seqno_and_condition` 배열에 각각의 `id`, `seqno`, `isRefrigerated` 정보가 포함됨
- 각 개체별로 예측 API 호출 필요

### 3. 필요한 컴포넌트들

#### A. 진행 상황 팝업 컴포넌트 (PredictionProgressModal) ✅ **완료**

- **오른쪽 상단에 작은 알림 형태로 표시** ✅
- **다른 탭으로 이동해도 사라지지 않음** ✅
- **최소화/최대화 기능** ✅
- 전체 진행률 표시 (1/11 진행중)
- 로딩 스피너
- 클릭 시 상세 정보 (성공/실패 등등) 표시

#### B. 예측 완료 결과 컴포넌트 (PredictionResultModal) ✅ **완료**

- **오른쪽 상단에 작은 알림 형태로 표시** ✅
- **최소화/최대화 기능** ✅
- 모든 예측이 완료된 후 표시
- 예측된 개체들을 리스트로 표시
- 같은 ID인 경우 묶어서 표시
- 각 개체 클릭 시 XAI 이미지 표시

#### C. XAI 이미지 컴포넌트 (XAIViewer) ✅ **완료**

- S3 URL 기반 이미지 표시
- 라벨별 이미지 슬라이더
- S3 base URL: `https://test-deeplant-bucket.s3.ap-northeast-2.amazonaws.com/`

## 주요 개선사항

### 🎯 **사용자 경험 향상**

- **작은 알림 형태**: 다른 작업을 방해하지 않음
- **고정 위치**: 오른쪽 상단에 항상 표시
- **최소화/최대화**: 필요에 따라 크기 조절 가능
- **다른 탭 이동 시에도 유지**: 작업 중단 없음

### 🎯 **레이아웃 최적화**

- **진행 상황 모달**: 오른쪽 상단 (right: 20)
- **결과 모달**: 진행 상황 모달 옆 (right: 340)
- **겹치지 않는 배치**: 두 모달이 동시에 표시되어도 깔끔함

### 🎯 **반응형 디자인**

- **최소화 상태**: 300px 너비로 간단한 요약 정보만 표시
- **최대화 상태**: 400px 너비로 상세 정보 표시
- **부드러운 전환**: CSS transition으로 자연스러운 애니메이션

### 🎯 **진행 상황 추적 개선** ✅ **최신 업데이트**

- **실시간 진행률 업데이트**: 각 예측 단계별 진행 상황 표시
- **개별 항목별 상태 추적**: ID, seqno, isRefrigerated 조합별 개별 진행 상황
- **상세 메시지 표시**: "데이터 조회 중...", "예측 중...", "예측 완료" 등 단계별 메시지
- **정확한 진행률 계산**: 실제 처리할 항목 수 기반 진행률 계산
- **에러 처리 강화**: 각 단계별 에러 상황을 개별적으로 추적하고 표시
- **실시간 진행 상황 업데이트** ✅ **최신 추가**: 각 예측 완료 시마다 즉시 진행률 업데이트
- **콜백 기반 진행 상황 동기화**: 예측 API에서 진행 상황 변경 시 즉시 UI 반영
- **초기 진행 상황 일괄 설정** ✅ **최신 추가**: 모든 예측 항목을 먼저 "대기중" 상태로 설정 후 순차 처리
- **진행률 단계별 표시**: 0/11 → 1/11 → 2/11 → ... → 11/11 순서로 진행률 표시
- **전역 상태 관리** ✅ **최신 추가**: React Context를 사용하여 다른 탭으로 이동해도 진행 상황 모달 유지
- **페이지 간 지속성**: Predict 페이지를 벗어나도 예측 진행 상황과 결과 모달이 계속 표시됨

## 사용 방법

1. **데이터 선택**: 테이블에서 예측할 데이터 선택
2. **예측 시작**: "예측하기" 버튼 클릭
3. **진행 상황 확인**: 오른쪽 상단 알림에서 실시간 상태 확인
4. **최소화/최대화**: 필요에 따라 알림 크기 조절
5. **결과 확인**: 완료 후 결과 알림에서 예측 결과 및 XAI 이미지 확인
6. **XAI 분석**: 각 항목의 "XAI" 버튼으로 상세 분석 이미지 확인
