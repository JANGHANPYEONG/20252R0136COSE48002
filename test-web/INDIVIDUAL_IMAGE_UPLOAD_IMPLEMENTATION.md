# 개별 이미지 업로드 시스템 구현 완료

## 개요
기존의 ZIP 파일을 통째로 서버에 업로드하는 방식에서, ZIP 파일을 압축 해제하여 개별 이미지를 해싱된 파일명으로 변경하고 presigned URL을 통해 S3에 직접 업로드하는 방식으로 변경되었습니다.

## 구현된 파일들

### 1. `src/API/add/uploadIndividualImages.js`
- **주요 기능**: 개별 이미지 업로드 핵심 로직
- **주요 함수들**:
  - `hashFileName()`: SHA-256 해시를 사용하여 파일명 생성
  - `getPresignedUrl()`: BE에서 presigned URL 요청
  - `uploadToS3WithPresigned()`: S3에 직접 업로드
  - `convertPngToJpeg()`: PNG를 JPEG로 변환
  - `uploadIndividualImages()`: 메인 업로드 함수

### 2. `src/components/ImageUploadProgress.js`
- **주요 기능**: 이미지 업로드 진행 상황을 사용자에게 시각적으로 표시
- **특징**: 
  - Material-UI를 사용한 현대적인 UI
  - 실시간 진행률 표시
  - 현재 처리 중인 파일명 표시
  - 단계별 상태 표시 (processing, uploading, completed)

### 3. `src/routes/DataRegister.js` (수정됨)
- **주요 변경사항**:
  - 새로운 개별 이미지 업로드 시스템 통합
  - 기존 ZIP 파일 업로드 로직을 개별 이미지 업로드로 교체
  - 진행 상황 표시 기능 추가
  - JSON 파일 생성과 이미지 업로드를 분리하여 각각 독립적으로 처리

## 시스템 워크플로우

### 1. 데이터 등록 버튼 클릭 시:
1. **유효성 검사**:
   - XLSX 파일 존재 확인
   - 데이터 존재 확인

2. **JSON 파일 생성 및 저장**:
   - `saveJsonToResult()` 함수를 통해 엑셀 데이터를 개별 샘플별 JSON 파일로 변환
   - 로컬 서버(`http://localhost:3001`)를 통해 `test-data/result` 폴더에 저장

3. **개별 이미지 업로드** (ZIP 파일이 있는 경우):
   - ZIP 파일 압축 해제
   - 각 이미지 파일에 대해:
     - PNG인 경우 JPEG로 변환
     - SHA-256 해시를 사용하여 파일명 생성
     - BE에서 presigned URL 요청
     - S3에 직접 업로드
   - 진행 상황을 실시간으로 UI에 표시

### 2. 파일명 해싱 규칙:
- 원본: `140119100857_s1_430nm.png`
- 해시: `abc12def_430nm.jpg` (SHA-256의 첫 8자리 + 파장 정보 + .jpg)

### 3. BE API 연동:
- **Presigned URL 요청**: `GET /upload/presigned-url?filename={hashedFileName}&content_type=image/jpeg`
- **S3 업로드**: Presigned URL을 사용한 multipart form 업로드

## 에러 처리

### 1. 개별 이미지 업로드 실패:
- 개별 이미지 업로드가 실패해도 JSON 파일 저장은 성공으로 처리
- 실패한 이미지에 대한 상세 정보를 콘솔에 로그
- 사용자에게 JSON은 저장되었지만 이미지 업로드 일부 실패를 알림

### 2. 전체 시스템 실패:
- 적절한 에러 메시지와 함께 사용자에게 알림
- 로딩 상태 해제
- 진행 상황 표시 숨기기

## 주요 개선사항

### 1. 성능 최적화:
- 개별 파일 업로드로 병목 현상 제거
- 실패한 파일만 재시도 가능 (향후 확장)
- 진행 상황 실시간 표시로 사용자 경험 개선

### 2. 보안 강화:
- SHA-256 해시를 사용한 파일명으로 보안성 향상
- Presigned URL을 통한 안전한 S3 업로드

### 3. 확장성:
- 개별 파일 처리로 향후 기능 확장 용이
- 파일별 메타데이터 관리 가능

## 설정 요구사항

### 1. 로컬 JSON 서버:
- 포트 3001에서 실행 중이어야 함
- `npm run json-server` 명령으로 실행

### 2. BE API:
- `config.js`의 `apiIP` 설정이 올바르게 구성되어야 함
- `/upload/presigned-url` 엔드포인트가 활성화되어야 함
